03修改方案

方案 1 · 窗口圆角 Win11 DWM API

在 MainWindow 构造后调用 DwmSetWindowAttribute(DWMWA_WINDOW_CORNER_PREFERENCE=33, DWMWCP_ROUND=2) 开启系统级圆角；监听 StateChanged，最大化时切 DONOTROUND 避免圆角残缺，还原时恢复。Win10 上 API 调用失败则静默保持直角。可选：用 DWMWA_BORDER_COLOR=34 去掉 Win11 默认描边，更贴合现有深色自绘边框。

MainWindow.xaml.cs（+30 行 P/Invoke）

方案 2 · 发送区视觉降噪 空态折叠 + 徽标圆点化

  • 附件托盘空态折叠：绑定 HasAttachments（需在 MainViewModel 补属性），无附件时托盘整体 Collapsed，空腔消失；有附件时保留圆角托盘但底色改用更轻的 SurfaceBrush、边框用 BorderSubtleBrush，降低叠框感。
  • 状态徽标圆点化：删除大色块 Border，设备名后改为 8px 状态圆点 + 小字状态，复用左侧设备列表已有的 StatusToBrushConverter（在线=绿 / 连接中=黄 / 失败=红 / 离线=灰），删除硬编码 #065F46，颜色全部走主题资源，与列表视觉语言统一。

现在

大深绿色块徽标（含状态文字），色块占位大、深色主题下文字对比度不足，且硬编码色值不随主题切换。

改后

8px 圆点 + 弱化状态小字，与左侧设备列表同一套状态色语言，深浅主题自动适配。

方案 3 · 英文 To: 间距 文案层修复

En.xaml 的 wsSendTo 从 "To: " 改为 "To"，间距改由 XAML 显式 Margin="0,0,4,0" 提供，不再依赖字符串尾随空格（WPF 会吞掉相邻 TextBlock 间空格）。中文「发送目标：」全角冒号自带间距，保持不变。

04实施顺序（确认后执行）

  1. 窗口圆角 + 最大化切换
    MainWindow.xaml.cs · 约 30 行 P/Invoke，Win10 静默降级直角
  2. 附件托盘空态折叠
    WorkspaceView.xaml + MainViewModel.cs · 约 10 行
  3. 状态徽标圆点化
    WorkspaceView.xaml · 约 15 行，复用 StatusToBrushConverter
  4. 托盘底色/边框降对比
    WorkspaceView.xaml · 2 个属性
  5. En.xaml To: 间距修复
    En.xaml + WorkspaceView.xaml · 2 行
  6. 主题资源巡检 + 编译验证
    dotnet build → 启动 → 截图对比 → 深/浅主题 × 中/英语言各验一遍
待确认的 3 个取舍：① 圆点化后是否保留「在线/离线」文字（建议保留，弱化为次要色）；② 附件托盘空态是完全隐藏还是留一条极简提示（建议完全隐藏）；③ Win10 无 DWM 圆角 API，接受「Win11 圆角 / Win10 直角」降级吗。
