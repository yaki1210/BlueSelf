  3. 附件托盘去容器
    UI/Views/WorkspaceView.xaml
    删托盘 Border（SidebarBgBrush 底 + 边框），保留横向 ItemsControl + AttachmentChip（chip 自带间距）；无附件时 ItemsControl Collapsed，复用现有 HasItemsToVisibilityConverter。
  4. 未选目标 placeholder 引导
    WorkspaceView.xaml + MainViewModel.cs
    新增 PlaceholderText 计算属性：未选目标 → wsTargetHint，已选 → wsPlaceholder；SelectedDevice 全部赋值点补通知；占位 TextBlock 改绑该属性；语言切换同步刷新。发送三合一校验不动。

    App.xaml

    Resources/Strings/Zh.xaml · En.xaml
    删除不再被引用的 wsSendTo（两语言），En 的 To: 尾随空格问题随之消失；wsTargetHint 保留转用作引导文案；wsAttachLabel 检查引用后处理。

    dotnet build → 启动 → 截图
