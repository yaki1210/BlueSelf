03实施中已核实的事实

① AddDevice 横幅图标 bug 比原计划描述更实锤：Text="{Binding IsScanning, Converter={StaticResource BoolToVis}}" 把 Visibility 结构体当文字绑定 → 必然显示异常，与截图吻合。② 顶栏按钮确实误用 wsRefresh（"刷新设备列表"）。③ ScannedDeviceItem.Kind 现为纯名字猜测（KindOfName），将被四信号替换。④ IsLikelyPeerDevice 的激进过滤是"扫不到新设备"的第二根因。
